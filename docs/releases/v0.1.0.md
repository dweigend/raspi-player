# Raspi Player 0.1.0 for macOS

Download **Raspi-Player-0.1.0-macos-arm64.dmg** from the assets below, open it,
and drag **Raspi Player.app** to **Applications**. Choose the DMG rather than
the source-code archives. Requires an Apple Silicon Mac (M1 or newer) running
macOS 13 or later. This release does not include an Intel or Windows build.

Python, Tk, the Raspberry Pi OS image and Raspberry Pi Imager are included.
No terminal setup or runtime downloads are required. The DMG includes the
illustrated German README as an offline HTML guide, source code and notices.

## First launch

This application is ad-hoc signed and **not notarized by Apple**. If macOS blocks
it, follow **System Settings > Privacy & Security > Open Anyway**, then confirm
opening the trusted application. macOS may ask for your Mac login password.
Writing an SD card may separately require an administrator password.
See [Apple's instructions](https://support.apple.com/de-de/guide/mac-help/mh40616/mac).
Managed Macs may restrict this exception. App Store installation is not required.

## Use and validation

Select the correct SD card, choose a local video and click **Create card…**.
**The selected card is completely erased.** Check the confirmation dialog and
wait for writing, verification and ejection to finish before removing the card.

The local macOS build was launched from a copy installed from its DMG. The
download is rebuilt by GitHub Actions from the release commit using Python
3.13.11. Bundle signature verification, asset-path tests, lint, type checks and
72 automated tests passed; one optional large-media test was skipped. The upload
workflow also checks the DMG checksum and frozen command-line entry point.
No new physical-card write or Pi playback test was performed for this release.

The `.dmg.sha256` asset contains the SHA-256 checksum. Downloads from this private
repository require a GitHub account with repository access.
